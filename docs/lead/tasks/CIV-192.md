RULES
1. Only Strateji may upload, preview and apply. One upload covers all directorates for the selected 2026 FR report revision(s).
2. Row match key: directorate (resolved through Kurum yapısı to the 2026 book department) + normalised indicator name (case/İ-ı, whitespace, punctuation, leading SH/PG code stripped). Exact match → "Eşleşti". Otherwise offer up to 3 candidates from the same directorate (difflib or equivalent) → "Onay gerekiyor": Strateji picks one or "Aktarma" per row in the preview. No candidate → "Eşleşmedi", not written. Never match by PG code alone. One Civensa indicator receives at most one workbook row; a second claim is an error row.
3. Annual value: use column "2026 YILI TOPLAMI" when it holds a number. Otherwise compute: TOPLA → Q1+Q2+Q3+Q4, only if all four are numbers; KÜMÜLATİF (any spelling) → Q4. Anything else blank. Blank is not zero: a row without a computable annual value is "Eksik", not written. Show Q1–Q4 and the chosen rule in the preview.
4. Scale: if the Civensa indicator unit or its 2026 target is a percentage on a 0–100 scale and the workbook value is ≤ 1 with unit "Oran", multiply by 100 and show "×100 (oran kesirden yüzdeye)" in the preview. If the scale cannot be decided, the row is "Onay gerekiyor" with both readings shown. Never convert silently.
5. Apply writes only confirmed rows, each as a new ActualRevision via save_actual with state "verified", explanation = workbook column 23 when present (else empty), evidence unchanged (keep the previous revision's evidence; the import adds none). If save_actual refuses a row (workflow state, permissions, deviation explanation required), skip that row and list it with the Turkish reason — do not bypass the rule. The import never edits indicator definitions, targets, or the PP book.
6. Re-running the same file is idempotent: rows whose value equals the current actual are reported "Değişmedi" and not written again.
7. Turkish UI, no new menu item: a "Excel'den içe aktar" block for Strateji on the existing /activity-reports screen. Preview table columns: Müdürlük (workbook / Civensa), Gösterge (workbook / Civensa), Yöntem, Q1–Q4, Yıllık değer, Mevcut değer, Durum, Seçim. Turkish number format 12.500,23. Summary counts on top.
8. Audit: one audit record per apply (file SHA-256, user, counts, row ids written); the raw file is not kept after the preview expires unless the existing import pattern already stores it.
9. Guide: replace the FR5 placeholder in docs/guides/mudurluk-fr-2026/KILAVUZ.md with 3–5 sentences: directorates send their rows to Strateji as today; Strateji imports; directorates check and correct on screen and add evidence. Keep the guide's label test green.
