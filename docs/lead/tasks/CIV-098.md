# CIV-098 — Modüller screen (034/033): icon grid instead of stacked rows

GOAL
Owner feedback (D-234): on the Modüller screen the three module cards are stacked full-width rows; text uses only the left half and the three modules are hard to take in at a glance. Change the layout to a grid of three equal cards, each with one simple line icon, so all three modules are visible and comparable at once.
