CIV-088 — AR-16 previous-year similarity warning

GOAL
In the activity report (Faaliyet Raporu) section editor, warn the user when a section's narrative text is more than 85% similar to the same section in the previous year's approved report. The warning never blocks saving, submitting or approving. Close gap AR-16 in docs/reports/civ-062-ar-gap-status.md (status line is updated by the lead later; do not edit that file).

CURRENT STATE
- Branch from `feature/authorization-workflow-phase5` (CIV-086 typeset contract #82 and CIV-089 CI are merged there).
- `app/activity_sections_service.py` `create_year(..., copy_previous=True)` finds the previous year's latest freeze (idare) or latest unit approval (birim) and copies blocks, setting `copied_from_id` / `copied_from_approval_id` and `copied_needs_review`. That "Geçen yıldan kopyalandı — gözden geçirin" flag is a different feature and must keep working unchanged.
- No similarity measure exists.

RULES (defaults chosen by the lead; Strateji may change them later, so keep them as named constants in one place)
1. Baseline: the same section code in the previous reporting year (year-1), same organization and same scope. Source = latest freeze for idare; latest approved unit version for a birim; verify the stored SHA-256 before use (same as create_year). Never use a draft.
2. Compared text: paragraph and list-item text of the section only. Exclude tables, the CORE section, EKLER and locked official statements (assurance).
3. Normalization: Turkish-aware lowercase (İ→i, I→ı), strip punctuation, collapse whitespace, replace every number (digits with . , separators) with one token "#", so changed figures alone do not lower similarity.
4. Measure: word-level similarity ratio on the normalized texts (difflib.SequenceMatcher on word lists, autojunk=False), shown as a whole percent. Threshold constant SIMILARITY_THRESHOLD = 85; warn when ratio > 85. Skip (no warning, no percent) when the normalized current text has fewer than 30 words.
5. States, each with its own Turkish text in the editor near the section text:
   - Above threshold: "Bu bölüm {yıl} yılı onaylı raporundaki aynı bölümle %{oran} benzer. Metni bu yılın gelişmelerine göre güncelleyin." plus a link/download to the baseline version used (freeze version or unit approval revision).
   - Baseline missing: "Karşılaştırma yapılamadı: {yıl} yılı için onaylı rapor bulunamadı."
   - Below threshold or too short: no warning.
6. Calculated on read (editor view and report completeness view), never stored in frozen payloads, never added to the typeset contract (ar-typeset/1) or Word/PDF exports.
7. Show the same warning, non-blocking, in the report completeness / missing list next to existing warnings, clearly separate from the "Geçen yıldan kopyalandı" item.
8. Strateji users see the percentage for every unit report in the completeness overview; unit users only for their own reports (reuse existing access checks).
