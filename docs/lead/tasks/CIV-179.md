Coder: Claude (lead, HIERARCHY v1.8 LEVEL 2 f, D-408). Reviewer: Codex ("@codex review") + CI. Branch task/civ-179-claude → feature/authorization-workflow-phase5. PR #382.

GOAL
AR-13 official look (D-354, D-407): the Faaliyet Raporu must come out in the 2025 printed book's own InDesign styles, so the designer (owner) lays out the 2026 book from Civensa data instead of retyping it.

CURRENT STATE (DOĞRULANDI, phase5 1d9f478)
- Word (CIV-046) and PDF (CIV-075) exist with Civensa's own layout; ar-typeset/1 (CIV-086) gives a stable JSON + CSV per table.
- 2025 book (docs/activity-report/source/2025-faaliyet-raporu.idml, D-407): each department chapter is ONE threaded story — headings, body text and inline tables. Styles used consistently: BOLUM BASLİK (chapter), arabaslik stun 2 / Arabaslik stun (sub-headings), Metin (body, bullets as "• "), TABLO (caption "Tablo N: …"), table style TABLO 1, cell/para styles tablo başlık / tablo yazı, cell style tablo sonuç (totals).

PRIOR ART
- Database publishing into InDesign is commonly done with InDesign Tagged Text: a text file carrying paragraph, character, table and cell style names; File > Place applies the document's own style definitions (Adobe "InDesign Tagged Text" reference; CreativePro). Chosen because the book's chapters are single stories and tagged text maps 1:1 onto them.
- Rejected: InDesign Data Merge (record-per-frame, unfit for long text); generating a whole IDML (frame geometry, overset handling, high risk); Word → Place (loses cell styles).
- Known risk: reports of tagged-text table import dropping formatting in edge cases (InDesign UserVoice) → owner placement test is the acceptance gate.

RULES
1. Pure function app/ar_indesign.py: input = verified ar-typeset/1 contract only; output = deterministic UTF-16LE (BOM) bytes, <UNICODE-WIN> header.
2. Route /activity-sections/reports/{id}/indesign.txt reuses ar_typeset_download.download → same source, access, version/approval selection as typeset.json.
3. Blank is not zero: blank indicator actual → "Kayıt yok"; verified 0 → "0".
4. Empty / not-applicable sections and tables without rows are not written; the JSON stays the full record.

OUTPUT / ACCEPTANCE
1. CI green (pure tests + PostgreSQL route test: bytes == tagged_text(typeset.json), access same as JSON).
2. Codex review addressed.
3. Owner placement test in InDesign (probe saglik-deneme.txt sent 4 Nov 18:40; then tests/artifacts/civ179/birim-ornek-indesign.txt): styles applied without "copy" duplicates, tables in TABLO 1, Turkish letters correct. Look approval is an owner item; fixes follow as CIV-179 follow-ups.
