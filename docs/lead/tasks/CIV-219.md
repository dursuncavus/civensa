Tablo 7 "Faaliyet ve Alt Faaliyet Bazında Çıktı ve Maliyet Gerçekleşme Tablosu": ONE row per activity the directorate is responsible for in the period's approved book (the activities already shown to the directorate; use the existing responsibility/catalogue links, do not let users add or rename activities). Amounts: Turkish format input (1.234.567,89), non-negative, right-aligned tabular digits. An activity not carried out: "Uygulanmadı" with a required reason instead of outputs/amounts. Section III-B-2 "Faaliyet ve Proje Bilgileri".
4. Tablo 8 "2026 Yılı Proje İzleme ve Gerçekleşme Tablosu": free rows: Proje Adı · İlişkili Program / Alt Program (select from the directorate's own programme/subprogramme rows of the book) · Başlama – Bitiş (two dates) · Fiziki (%) 0–100 · Harcama (TL) · Durumu (Devam ediyor / Tamamlandı / Başlamadı / İptal). Zero rows allowed with an explicit "Bu yıl proje yok" choice. Same section as Tablo 7.
5. Activity photos: per Tablo 7 row optional JPG/PNG uploads with a caption; numbered automatically in report order ("Fotoğraf 1, 2 …"). Reuse the existing evidence upload storage and limits; no new storage backend.
6. Indicator deviation rule (rehber "Sapma Açıklama Kuralı"): an explanation is required only when |actual − target| / |target| ≥ 10 % (target 0: any non-zero actual). 8. Export: the existing unit report Word/PDF export and the Strateji consolidated view include the tables with their numbers (Tablo 1, 2, 7, 8) and the photos list. Table/paragraph style names follow the existing export; no new fonts.
9. Permissions: directorate staff edit their own department only; Strateji read-all; no other directorate can see another's tables (existing scope checks).
