GOAL
Some indicators are better when the actual is lower than the target (durations in days). Today every comparison assumes higher is better, so the council scorecard ("karne") and the indicator ratio columns misjudge them (D-424 risk; the karne must not be shown to the council until this is fixed). Strateji answered on 9 Nov 2026 (D-446, S10): the lower-is-better indicators are the 4 "Gün" indicators of the 2026 workbook (Zabıta: istek ve şikâyetlerin cevaplandırılma süresi; Yazı İşleri: evrakın birime ulaşma süresi, nikah işlemlerinin sonuçlandırılma süresi, 4109 yardım süresi). Give Strateji a way to mark an indicator "Düşük değer daha iyi" and use that direction everywhere a target is compared with an actual.

DECISIONS (lead)
1. Storage: a new append-only table (e.g. `indicator_directions`: persistent `indicator_id`, `period_id`, `direction` in {'higher','lower'}, `reason` text, `created_by`, `created_at`); the latest row per (indicator_id, period_id) wins; no row = 'higher'. Additive migration only, down_revision `c192a1b2c3d4`.
2. Setting it: Strateji only, on an existing Strateji screen that already lists the period's indicators (pick the one nearest to the indicator report; no new menu). A select "Yön": "Yüksek değer daha iyi" / "Düşük değer daha iyi", a required reason, audited. Changing it after a report is frozen does not alter that frozen report.
3. Freezing: `core_summary` adds `'direction'` to each indicator so a frozen release keeps the direction it was approved with. A frozen payload without the key is read as 'higher'.
4. Comparison rule (one shared helper, used by all three places in 3.):
   - higher: met if actual ≥ target; ratio = actual ÷ target × 100 (target > 0).
   - lower: met if actual ≤ target; ratio = target ÷ actual × 100 when actual > 0; when actual = 0 the indicator is met and the ratio shows "—".
   - Thresholds and wording otherwise unchanged. Update the karne note to: "Yüksek değer daha iyi göstergelerde gerçekleşen ≥ hedef, düşük değer daha iyi göstergelerde gerçekleşen ≤ hedef, hedefte sayılır." and mark lower-is-better rows visibly (e.g. "↓" or "(düşük daha iyi)") in the scorecard detail and the two ratio tables.
5. Not in scope: no automatic detection from unit or name ("Gün" is how Strateji found them, not a rule); no seeding of the 4 real indicators in a migration — Strateji sets them in the live system after release (the lead gives the owner the steps).
