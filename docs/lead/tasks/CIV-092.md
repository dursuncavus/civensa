Make dursuncavus/civensa safe to switch to a public repository (GitHub Actions minutes are free for public repos; D-219/D-220). This task prepares only. It does NOT change repository visibility and does NOT delete existing artifacts — those are owner-approved steps the lead runs afterwards.

Update restore paths (preprint rehearsal, clear-preprint, any ops script) to decrypt with `BACKUP_AGE_IDENTITY`; secrets must never be available on pull_request jobs (keep restore on workflow_dispatch/schedule only).
