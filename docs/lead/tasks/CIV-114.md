# CIV-114 — 023 Strateji inceleme görünümü: read-only look of the data-entry screen

GOAL
Screen 023 is the strategy user's view of /department/{id} (same template as 024, department.html, already on the design system via CIV-097/CIV-100). Make every read-only state of this screen look read-only, so a strategy reviewer (and a department user after submit or period close) never sees fields that look editable but are not. No other redesign.

PRIOR ART (D-271)
GOV.UK / NHS design-system guidance: read-only data is shown as plain text or a clearly non-interactive field, not as an editable-looking input (GOV.UK "summary list" pattern for check-your-answers pages). Reuse existing design tokens and the 024 styles in app/static/design/data-entry.css; do not invent a new pattern.

CURRENT STATE
- app/templates/department.html renders inputs/textareas with `readonly` (and selects/checkboxes `disabled`) when `user.role!='department' or period.status=='closed' or submission.status in ['submitted','approved']`. Edit buttons are already hidden in those states.
- Reference capture of the old look: docs/screenshots/ui-map-v1/023-department-strategy.png.
- data-entry.css styles inputs the same whether readonly or not (verify).

WORK
1. Add one wrapper modifier on `div.data-entry-page` when the page is read-only (same condition as above, computed once in the template with `{% set %}`), e.g. class `is-readonly`. No change to any input attribute, id, class, data-* or form.
2. In app/static/design/data-entry.css, under that modifier only: readonly inputs/textareas and disabled selects/checkboxes get a non-editable look (no input border/shadow, subdued background from tokens, normal text colour, default cursor, no focus ring that suggests typing — keyboard focus must still be visible). Tokens only. Text contrast ≥ 4.5:1.
3. Editable 024 (department draft) must render byte-identical HTML, and its computed styles must not change (test it).

RULES
- AGENTS.md applies. Never merge; never touch main/staging, docs/lead/** or AGENTS.md; no database, migration, route, API, write path or permission change. Synthetic data only.
- Do not edit shared files: base.html, shell.css/js, tokens.css, app.css, app.js, other templates. No new dependency. No uppercase text-transform. No text changes.

CONSTRAINTS
Only: app/templates/department.html (wrapper class line only), app/static/design/data-entry.css, tests/test_data_entry_design.py or a new tests/test_department_readonly_design.py (+ fixtures), docs/design/rollout/civ-114/**.
