# CIV-128 — Reconciliation table: short status, details on demand

Base branch: `feature/authorization-workflow-phase5`. Follow AGENTS.md. Never merge. Open the PR into `feature/authorization-workflow-phase5`.

GOAL
Owner feedback (27 Oct, D-297): the "Maliyet Ara Toplamları ve Kaynak Mutabakatı" table is read-only, but every row's "Durum / Yapılacak İşlem" cell prints the full error and warning messages, and the same long message repeats for each year row. Make the cell a short status and keep the full messages one click away.

PRIOR ART
Existing components only: text status badges and `<details>` disclosures already used on these pages (report-preparation.css, source-comparison.css), warning/error info panels. Owner rule D-292: a status sits next to its label.

CURRENT STATE
- app/templates/pp_reconciliation.html (shared include in program.html, source_comparison.html, report_builder.html). Row data from app/program_service.py (~line 505): `status` ("Yayın engeli" / "Uyarı" / "Mutabık"), `errors` list, `warnings` list.
- Durum cell today: `<strong>{{ row.status }}</strong>` + every error as `<p class="field-error">` + every warning as `<p class="muted">`.
- Tests that read this table: tests/test_pp_subtotal_reconciliation.py, test_pp_errors_forms.py, test_source_comparison_design.py, test_report_preparation_design.py (grep for "pp-reconciliation", "Yayın engeli", "field-error", "kaynak toplamı yok").

WORK
1. Durum cell: the status as a text badge (Yayın engeli danger-light, Uyarı warning, Mutabık success; text always present), then one short secondary line with counts only when non-zero, e.g. "2 hata · 1 uyarı".
2. When a row has errors or warnings: a `<details>` under that line, summary "Ayrıntı", closed by default, containing exactly the same messages in the same order and with the same classes as today (`p.field-error`, `p.muted`).
3. Above the table (inside #pp-reconciliation, after the intro paragraph): one summary panel only when at least one row has errors — warning panel text "{n} satırda yayın engeli var. Ayrıntıyı ilgili satırdaki “Ayrıntı” bağlantısından açın." (n = number of rows with errors). No panel when n = 0.
4. Styles for the badge, count line, details and panel go into the page CSS files that already style #pp-reconciliation on each page (report-preparation.css, source-comparison.css; report builder: only if it already has a design-system CSS, otherwise leave its look as is). The table must still fit its panel at ≥ 1280 px (CIV-124) and scroll inside `.table-wrap` below that.
