CIV-160 İç Kontrol anlatı bölümleri

Follow AGENTS.md. Base branch: feature/authorization-workflow-phase5. Never merge, never deploy, never connect to the live database.

GOAL
Add the narrative sections of the six-month İç Kontrol monitoring report (gap G6 from CIV-082) to the CIV-079 monitoring module: Misyon, Vizyon, one evaluation text per İç Kontrol component, Güçlü yönler, Gelişim alanları, Öneriler and Puan aralığı. Strateji writes them per monitoring period, Strateji Müdürü approves, the approved revision is frozen, and the approved text appears in the CIV-084 official Word report. Directorates see only the approved Misyon and Vizyon, read-only.

WORK
1. Narrative record per period. One narrative per monitoring period with these fields (plain text, line breaks kept, trimmed; blank allowed while in draft):
   - Misyon (max 2.000 characters), Vizyon (max 2.000)
   - Bileşen değerlendirmesi: one text per component of the period's plan, in catalogue order, labelled with the catalogue name (max 8.000 each)
   - Güçlü yönler, Gelişim alanları, Öneriler (max 8.000 each)
   - Puan aralığı: a short label typed by Strateji, e.g. "76-90 Puan Aralığı" (max 100), and Puan aralığı açıklaması (max 2.000)
2. Editor (Strateji only). New "Rapor anlatı bölümleri" screen linked from the Strateji monitoring overview of the selected period. Strateji Personeli or Müdürü saves; every save stores the full set of fields as a new immutable revision. Over-length input: Turkish error naming the field and the limit, values kept. Stale revision: refused with the existing "sayfayı yenileyin" message pattern.
3. Copy from the previous period. On a period with no revision yet, button "Önceki dönemden kopyala" copies every field of the latest APPROVED revision of the most recent earlier period of the same plan into a new draft revision (recorded as a save by the clicking user). If there is none: Turkish message, nothing saved.
4. Workflow. Submit (all of Misyon, Vizyon, every Bileşen değerlendirmesi, Güçlü yönler, Gelişim alanları, Öneriler and the Puan aralığı label must be non-blank; Turkish message lists the empty field names; values kept) → Strateji Müdürü returns (reason required) or approves; approved → reopen with reason creates a new draft and keeps the old approval in history. Separation of duties exactly as CIV-079: a Müdür who entered or changed that revision's data cannot approve it. Closed period: no save, submit or decision. Directorate users: 403 on every editor and decision route.
5. Reference figure. Next to Puan aralığı show read-only the CIV-085 institution questionnaire score for the same period (Toplam puan / azami, Gerçekleşme oranı, number of approved directorates) from the existing questionnaire service, or "—" when none. Do not derive or suggest a band from it.
6. Directorate view. On "İç Kontrol Eylemlerimiz" for the selected period, a read-only block "Misyon ve Vizyon" with the latest APPROVED Misyon and Vizyon of that period; hidden when there is no approved revision. No other narrative field is shown to directorates.
7. Official Word report. official_export(…, 'docx'): when the period has a narrative, insert after the cover lines and before the page break, in this order: Misyon, Vizyon, Bileşen değerlendirmeleri (one sub-heading per component), Puan aralığı (label + açıklama), Güçlü yönler, Gelişim alanları, Öneriler; each line of text becomes its own paragraph. Final (non-draft) report uses only the latest approved revision; if a narrative exists but its current state is not approved, the final download is refused (409, Turkish: "Rapor anlatı bölümleri onaylanmadı. Strateji Müdürü onayını tamamlayın veya TASLAK indirin."). TASLAK uses the latest revision and marks each section heading "(taslak metin)" when it is not approved. When the period has no narrative at all, the Word output stays byte-for-byte as today. The official Excel and all other exports stay byte-for-byte unchanged.
8. History and immutability. Revisions and events are append-only (reuse reject_history_change and the PostgreSQL guard pattern of CIV-085). History list on the editor: action, actor, reason, TSİ time.
9. Migration: exactly one new migration on top of c085a1b2c3d4. Downgrade refuses with a Turkish message when any narrative data exists; drops the new tables only when empty.

Docs: add a "Rapor anlatı bölümleri (CIV-160)" section to docs/internal-control/izleme.md (Turkish): fields and limits, who writes/approves/sees, copy from previous period, Word placement, the rule that the system does not compute the band ("puan aralığı Strateji tarafından yazılır; sistem bant hesaplamaz").
