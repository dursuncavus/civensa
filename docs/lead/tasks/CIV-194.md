CIV-194 Kesin hesap PDF → malî bilgiler XLSX dönüştürücü (ML1)

Follow AGENTS.md. Base branch: feature/authorization-workflow-phase5. Never merge, never deploy, never connect to the live database.

GOAL
Mali Hizmetler has no Excel for budget actuals; Strateji receives the year-end final accounts as PDF ("Bütçe Gider Kesin Hesap" and "Gelir Cetveli Kesin Hesap Dökümü") and said to treat them as the data source (D-446). Build an offline converter that turns these PDFs into Civensa's existing financial import workbooks (Faaliyet Raporu III.A.1, kinds "expenditure" and "revenue"), so Strateji/Mali Hizmetler upload them through the existing XLSX preview/apply flow. The 2026 final account arrives Jan–Feb 2027; it must work then.

CURRENT STATE (DOĞRULANDI by the lead on the real 2025 PDFs, which are NOT in the repo)
- Gider PDF: text PDF (producer OpenPDF), landscape, ~19 pages. Header columns: Kurum Kodu | Fonksiyonel Kodu | Finansal Kodu | Ekonomik Kodu | Açıklama | Geçen Yıldan Devreden Ödenek | Bütçe İle Verilen Ödenek | Ek Ve Olağanüstü Verilen Ödenek | Aktarma Suretiyle Eklenen (+) | Düşülen (-) | Net Ödenek Toplamı | Bütçe Gideri Toplamı | Ödenen Bütçe Gideri | Ödenek Üstü Harcama | İptal Edilen Ödenek | Gelecek Yıla Devrolan Ödenek. Amounts in Turkish format (5.100.000.000,00).
- Rows are a code hierarchy: "46" (BELEDİYE) → "46 34" → "46 34 14" (BÜYÜKÇEKMECE) → "46 34 14 NN" (directorate, NN = budget code, e.g. 10 BİLGİ İŞLEM MÜDÜRLÜĞÜ) → functional levels "01", "01 3", "01 3 9", "01 3 9 00" → finansal "5" → ekonomik level 1 "01" (PERSONEL GİDERLERİ) … Directorate names may wrap onto a second line ("İNSAN KAYNAKLARI VE" / "EĞİTİM MÜDÜRLÜĞÜ").
- Gelir PDF: 1 page, columns: Gelirin Kodu (I II III IV V) | Açıklama | Bütçe ile Tahmin Edilen | 2024 Yılından Devreden Gelir | 2025 Yılı Tahakkuku | Toplam Tahakkuk | 2025 Yılı Tahsilatı | Red ve İadeler | Yılı Net Tahsilatı | 2026 Yılına Devreden Tahakkuk | Oran. Numbers wrap across lines in the text layer (e.g. "199.974.608,8" / "6").
- Civensa import workbook: app/activity_financial_service.py template(kind) / budget_columns(kind): expenditure = Müdürlük No, Ekonomik Kod, Başlangıç Ödeneği, Eklenen Ödenek, Düşülen Ödenek, Bildirilen Yıl Sonu Ödeneği, Harcama (Gerçekleşme), İptal Edilen Ödenek, Ertesi Yıla Devreden Ödenek, Sapma Açıklaması; revenue = Ekonomik Kod, Bütçe Tahmini, Tahsilat (Gerçekleşme), Red ve İadeler, Sapma Açıklaması. "Müdürlük No" is the Civensa department id.
- Budget codes were renumbered between 2025 and 2026 (Strateji list 9.11.2026, D-447); Kurum yapısı (app/structure_service.py) stores budget_code per department and period.

PRIOR ART
Internal: pypdf is already a dependency (requirements-dev/requirements); the financial template/preview/apply flow stays the import path — the converter only produces its input. Prefer pypdf text extraction with layout/word positions over regex on a flattened string; if pypdf positions are insufficient, use pdfplumber-like column bucketing implemented with pypdf's visitor API (no new dependency).
Industry pattern: extract → normalise → reconcile totals → emit, with a reconciliation report.

RULES
1. CLI script scripts/kesin_hesap_xlsx.py: `--gider PDF` and/or `--gelir PDF`, `--year`, `--departments CSV` (columns: budget_code, department_id, department_name — exported by the operator from Civensa; no database access in the script), `--out DIR`. Outputs: expenditure.xlsx and/or revenue.xlsx in exactly the template's columns and sheet name, plus report.md (Turkish).
2. Expenditure rows: one row per (directorate, ekonomik level-1 code 01–09) summed over functional/finansal codes. Mapping: Başlangıç Ödeneği = Geçen Yıldan Devreden + Bütçe İle Verilen; Eklenen Ödenek = Ek ve Olağanüstü + Aktarma Eklenen; Düşülen Ödenek = Aktarma Düşülen; Bildirilen Yıl Sonu Ödeneği = Net Ödenek Toplamı; Harcama (Gerçekleşme) = Bütçe Gideri Toplamı; İptal Edilen = İptal Edilen Ödenek; Ertesi Yıla Devreden = Gelecek Yıla Devrolan. Write the mapping into report.md.
3. Revenue rows: one row per level-1 revenue code with Bütçe Tahmini = Bütçe ile Tahmin Edilen, Tahsilat = Yılı Tahsilatı, Red ve İadeler = Red ve İadeler. Re-join wrapped numbers only when the joined value reconciles with the row's other columns (Toplam Tahakkuk = Devreden + Yılı Tahakkuku; Net = Tahsilat − Red); otherwise the row is an error, not a guess.
4. Reconciliation (blocking): per directorate, the sum of emitted ekonomik rows equals the directorate line of the PDF for every column; the sum of all directorates equals the "46 34 14" line; revenue level-1 rows sum to the PDF total line if present. Any mismatch → non-zero exit, no XLSX written, report lists the differences.
5. Unknown budget code (not in --departments CSV) → non-zero exit listing the codes and names; never drop or merge silently. Blank is not zero.
6. No network, no database, no writes outside --out.
