RULES
1. Karne slide: one row per Stratejik Plan amaç (fallback: per müdürlük): code, name, "N göstergenin M'i hedefte", bar, percentage, status pill. Rate = indicators that met their target / indicators with a verified actual and a single verified target. Direction: if the data model marks lower-is-better indicators, respect it; otherwise actual ≥ target counts as met and state this assumption in the PR. Status thresholds as constants in one place: ≥ 90 "Hedefte", 70–89 "Yakın", < 70 "Geride" (to be confirmed by Strateji). Summary line above the rows (count per status). Max 6 rows per slide, continue with "Tablo i/n".
2. Açılım popup: every row that is "Yakın" or "Geride" gets the "+" marker and opens a popup over the same slide (no slide change): missed indicators with Gösterge, Müdürlük, Hedef, Gerçekleşen, Oran, Sapmanın nedeni (the unit's explanation/deviation text; blank → "—"). × button and Esc close it; Reveal keyboard is disabled while open and re-enabled on close; changing slide closes it; the deck continues from the same slide. More than 8 missed indicators → the popup body scrolls. PDF (#pdf): each popup is printed as its own page right after its karne page (same look, no × or hint).
3. Bütçe dağılımı slide: economic categories' share of actual expenditure as "TL per 100 TL" (one decimal, Turkish format), treemap with the three largest named on the left; categories under 5 % merged into one "Diğer (…)" box listing their names. Skip the slide (log line) if any actual is blank or the total is not complete — never show zeros.
4. Place the karne in the "Göstergeler" group before the existing summary table; the budget slide in the "Bütçe" group after the KPIs.
5. CIV-182 LOW fixes: "Ortalama oran (%)" always with one decimal (62,5 / 75,0); no "Tablo 1/1" marker when a table fits on one slide (engine-wide).
6. Numbers only from the pinned approved payload; Turkish number format via app/numbers.py; blank/null shown as "—"; texts in Turkish exactly as the reference.
