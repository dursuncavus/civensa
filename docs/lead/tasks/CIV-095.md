# CIV-095 — UI design system + 3 screens as a static prototype

GOAL
Build the new Civensa look as a static HTML/CSS prototype: a design system page and three redesigned screens. The owner approves it from screenshots; later tasks apply it to the real templates module by module. This task changes NO application code.

CURRENT STATE
- Screen map (CIV-093): docs/screenshots/ui-map-v1/ — INDEX.md lists every screen, its role and every link/button/form with its target; 97 PNGs.
- Approved design principles (D-224, research brief by the lead): light theme only; calm, high contrast; one accent colour used only for meaning; one topic per page; a "what is left" list and one primary action at the top of each report; labels above fields in sentence case (no ALL CAPS, no placeholder-only labels); errors next to the field with an icon, plus a summary; destructive actions hidden in a secondary menu with a separate confirm dialog; no decorative motion, gradients or shadows; numbers right-aligned with tabular figures, unit in the column header, never inside cells.
- Current problems to fix (from 034/024/012): tiny uppercase labels; inconsistent button sizes; "Göstergeyi Kaldır" confirmation open inline mid-form; dark sidebar ends before page bottom on long pages; section status only as small grey text; table input taught as "| Başlık | Değer |" syntax; default blue underlined back link.

TOKENS (use exactly; put them in docs/design/prototype/tokens.css as CSS custom properties)
- Colours: --bg #F6F5F2; --surface #FFFFFF; --surface-muted #EFEDE8; --border #E3E1DC; --text #1F2328; --text-secondary #545B64; --accent #1E6B65; --accent-hover #17554F; --accent-soft #E3F0EE; --success #1E7A46 / bg #E6F4EA; --warning #8A5A00 / bg #FFF4D6; --danger #B42318 / bg #FDECEA; --focus 2px solid var(--accent) with 2px offset.
- Type: Fira Sans 400/500/600 (SIL OFL), self-hosted woff2 under docs/design/prototype/fonts/ with its licence file; fallback system-ui. If the font cannot be downloaded in your environment, use system-ui and say so in the PR. Sizes px: 14 (labels, table, meta), 16 (body, inputs), 18 (card titles), 20, 24 (page title), 30 (rare). Body line-height 1.5; text blocks max 72ch. Tables: font-variant-numeric: tabular-nums.
- Spacing 4-based: 4, 8, 12, 16, 24, 32, 48. Radius 6px. Control height 40px. Table rows 40px (financial tables 32px). Sidebar 248px, LIGHT (surface colour + right border), full page height.
