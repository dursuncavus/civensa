# CIV-117 — Bound the waits in the hang-candidate tests

GOAL
CI shard 1 hung three times (D-283). CIV-115 (#167) adds a 300 s per-test timeout, but its own PR proves a Python signal timeout cannot stop a thread stuck in `Barrier.wait()` or `ThreadPoolExecutor.__exit__`, so those tests can still hang the job until the job cap. Make every wait in the candidate tests bounded so a stuck race fails fast with a clear message instead of hanging. Test code only; product behaviour unchanged.

PRIOR ART (D-271)
Standard library only: `threading.Barrier(parties, timeout=...)` raises `BrokenBarrierError`; `Future.result(timeout=...)` raises `TimeoutError`; `ThreadPoolExecutor.shutdown(wait=False, cancel_futures=True)`; `subprocess.run(..., timeout=...)` raises `TimeoutExpired`. No new dependency.
