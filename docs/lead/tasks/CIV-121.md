# CIV-121 — 021 Müdürlük ilerleme panosu: compact label/number list

Base branch: `feature/authorization-workflow-phase5`. Follow AGENTS.md. Never merge. Open the PR into `feature/authorization-workflow-phase5`.

GOAL
On the strategy home (/dashboard, role strategy, screen 021) the "Müdürlük ilerleme panosu" shows six big cards (3 columns × 2 rows) and, above them, a sentence that repeats the same six numbers. The labels never change; only the numbers do. Owner feedback (27 Oct): too much space for six numbers. Make it a compact list: label on the left, number on the right of the same row.

Thin separators between rows, no card boxes.
2. Layout: at ≥ 1024 px two columns of three rows; below 1024 one column. At 390 no horizontal scroll; long labels wrap without overlapping the number.
3. Remove the muted sentence under the heading that repeats the six numbers (`<p class="muted">{{ progress_summary.approved }} onaylanan müdürlük · …`). Nothing else in the section changes (buttons, filter status line, table).
4. Styles only in `app/static/design/dashboard.css`, scoped to `#mudurluk-ilerleme`; tokens from tokens.css; no uppercase text-transform; the active-filter state stays visible (not by colour alone — keep the existing pressed style or an outline).
