## Evidence conventions and method

- **READ**: inspected source, registered routes, models, templates, migrations, documentation or tests. Reading a test does not establish that it passed.
- **EXECUTED E…**: independent requests to the unmodified loopback Uvicorn server, using `httpx`, genuine `/login`, signed session cookies and the session's CSRF token. No dependency overrides, forged sessions or replacement authentication were used.
- **EXECUTED B…**: headless Chromium/Playwright, normal login, rendered screens and actual form clicks. The browser ledger explicitly names the actions.
- **EXECUTED T01**: completed existing repository test selection; its own dependency overrides/fixtures apply. Unmarked tests use SQLite; `postgres` tests use isolated PostgreSQL schemas. These tests supplement, rather than replace, E/B PostgreSQL product-flow evidence.
